# 拾光 · 每日学习

一个无需安装依赖的每日学习计划网站，使用原生 HTML、CSS、JavaScript。

## 本地启动

需要 Node.js 18 或更新版本：

```bash
cd /Users/gaoxinghang/workspace/daily-study
npm start
```

浏览器访问 http://localhost:3000 。按 Ctrl+C 停止服务。
端口被占用时，可使用 `PORT=3001 npm start`。

## 功能

- 新建、删除每日任务，支持分类、备注和 1～480 分钟自定义时长。
- 开始、暂停、恢复、重置计时；只有倒计时结束才自动完成。
- 一次只计时一个任务，切换任务会暂停原任务。
- 任务清单按全部、待完成、已完成筛选。
- 实时统计今日任务、已专注分钟数及完成率。
- 本地自动保存，刷新或关闭页面不会暂停已经开始的计时。
- 按本地时区每日零点归档，计划保留，计时与完成状态重置。
- 查看最近 30 条有记录日期（含今天）的学习足迹。
- 响应式布局，适配桌面和手机；无外部字体或图片依赖。

初次访问提供三项可删除的入门计划。
添加的任务默认每日重复，不是只存在于当天。
跨午夜的计时仅计入前一天午夜以前的部分，不自动开始次日计时。
重置或删除任务会清除该任务当天计入的专注时长。

## 数据说明

数据只存储在当前浏览器的 localStorage，不上传服务器、不跨设备同步。
请勿清理网站数据；无痕模式关闭后通常会丢失进度。
更换访问域名或端口，也会使用另一份本地记录。
计时以设备时间为准，修改系统时钟会影响结果。

这是本地优先的前端网站，没有账号系统和云端备份。
`server.js` 仅用于本地预览，静态文件也可部署至静态托管平台。
