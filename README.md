# 拾光 · 每日学习

一个无需安装依赖的每日学习计划网站，使用原生 HTML、CSS、JavaScript。

## 本地启动

需要 Node.js 18 或更新版本：

```bash
cd /Users/gaoxinghang/workspace/daily-study
npm start
```

浏览器访问 http://localhost:3000 。按 Ctrl+C 停止服务。
端口被占用时，可使用 `PORT=3001 npm start`。
电脑重启后需要重新运行启动命令，不会自动开机启动。

## 手机与其他电脑访问

服务默认监听 `0.0.0.0:3000`，允许其他设备通过网络访问。
启动后终端会列出本机地址和网络地址。

1. 手机或其他电脑连接同一 Wi-Fi / 局域网。
2. 打开终端输出的 Wi-Fi 或有线网卡地址，例如：
   `http://192.168.31.105:3000`，以当前实际输出为准。
3. 不要在手机上使用 `localhost`、`127.0.0.1` 或 `0.0.0.0`。
4. 页面会随屏幕宽度自动切换布局，无需安装 App。

电脑需要保持开机、联网且服务运行；休眠时服务可能无法访问。
如果访问失败，请检查 macOS 防火墙是否允许 Node.js 入站连接，
并确认不是启用了设备隔离的访客 Wi-Fi。不要直接关闭整个防火墙。
切换网络或重启路由器后 IP 可能改变，请重新查看启动输出。
输出中可能包含 VPN 等虚拟网卡地址，需选择实际局域网网卡地址。

默认没有账号或访问密码，可连接本机该端口的设备均可获取网页，
请只在可信网络运行。不需要共享时，可改为仅本机访问：

```bash
HOST=127.0.0.1 npm start
```

这不是公网部署。不同网络、手机流量访问需要另行部署到带 HTTPS
的静态托管服务，或配置受控的网络入口；无需为此直接开放路由器端口。
手机与电脑各自保存学习记录，当前不跨设备同步。

## 功能

- 新建、编辑、删除每日任务，支持分类、备注和 1～480 分钟自定义时长。
- 开始、暂停、恢复、重置计时；只有倒计时结束才自动完成。
- 一次只计时一个任务，切换任务会暂停原任务。
- 任务清单按全部、待完成、已完成筛选。
- 实时统计今日任务、已专注分钟数及完成率。
- 本地自动保存，刷新或关闭页面不会暂停已经开始的计时。
- 按本地时区每日零点归档，计划保留，计时与完成状态重置。
- 查看最近 30 条有记录日期（含今天）的学习足迹及累计汇总。
- 晨曦纸本 / 静夜书房两套主题，可切换并可关闭完成提示音。
- 沉浸专注模式，只保留计时器。
- 快捷键：空格开始/暂停，N 新建任务，F 切换沉浸模式，Esc 退出。
- 今天已专注 N 分钟后，新时长只能改到 N+1 分钟以上；
  今日已完成的任务不可修改时长（仅可修改名称、分类或提示）。
- 响应式布局，适配桌面和手机；无外部字体或图片依赖。

初次访问提供三项可删除的入门计划。
添加的任务默认每日重复，不是只存在于当天。
跨午夜的计时仅计入前一天午夜以前的部分，不自动开始次日计时。
重置或删除任务会清除该任务当天计入的专注时长。

## 数据说明

数据只存储在当前浏览器的 localStorage，不上传服务器、不跨设备同步。
请勿清理网站数据；无痕模式关闭后通常会丢失进度。
更换访问域名或端口，也会使用另一份本地记录。
计时以设备时间为准，修改系统时钟会影响结果。

这是本地优先的前端网站，没有账号系统和云端备份。
`server.js` 用于本机和可信局域网访问，静态文件也可部署至静态托管平台。
